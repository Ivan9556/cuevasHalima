# Cuevas Halima - API Rest de Reservas

Este proyecto está desarrolado como ejemplo práctico de una **API Rest** con el objetivo de proporcionar a una pagina web de alojamientos rurales un sistema de reservas.

## Tecnología empleadas

Python para Backend
HTML5 y CCS3 para Frontend
JavaScript dar cierta funcionalidad al frontend

## Variables de entorno

Esta API se ha construido con variables de entorno. Para poner en práctica este ejemplo de API Rest es necesario un archivo *.env* y asignarle las variables correspondientes.
